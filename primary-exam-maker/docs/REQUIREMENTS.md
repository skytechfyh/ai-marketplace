# primary-exam-maker 需求文档

> 状态：需求已确认，尚未实现。插件尚未注册到 `.claude-plugin/marketplace.json`，待 P0 骨架完成后一并注册（初始版本 0.1.0）。
>
> 原始需求对照：①错题图片/文档定向专项 → F1；②按题型专项 → F2；③单元测验 → F3；④期中卷 → F4；⑤期末卷 → F5；⑥多科目、1-6 年级可扩展 → 数据按年级/学科分文件，第一版只做二、三年级。

## 1. 定位

家庭使用的小学学习辅助 skill：家长给孩子生成**可打印**的练习与试卷，家长阅卷，并把错题沉淀下来做长期复习。

- 使用者：家长（自用），目前两个孩子：二年级、三年级
- 学科：语文、数学、英语；年级范围先做二、三年级，数据结构需能扩展到 1-6 年级与其他学科
- 教材：

| 学科 | 教材版本 | 出版社 |
|---|---|---|
| 语文 | 统编版 | 人民教育出版社 |
| 数学 | 苏教版 | 江苏凤凰教育出版社 |
| 英语 | 译林版（牛津小学英语） | 译林出版社 |

## 2. 功能清单

### 2.1 出题类

| 编号 | 功能 | 说明 |
|---|---|---|
| F1 | 错题定向专项 | 输入图片/PDF/doc/MD 中的错题 → 识别 → 错因归类 → 同构变式 + 迁移变式。识别结果需让家长确认 |
| F2 | 题型定向专项 | 按指定题型（如“看拼音写词语”“两位数加减法应用题”）生成 |
| F3 | 单元测验 | 指定册次与单元范围，如“二年级上册 1-2 单元” |
| F4 | 期中试卷 | 覆盖前半册，带双向细目表 |
| F5 | 期末试卷 | 以本学期为主，是否含上学期内容可选 |
| F6 | 口算卡 | **由代码生成**，范围可控、不重复、答案绝对正确 |
| F7 | 听写单 | 语文生字词、英语单词；语文可生成音频 |
| F8 | 知识点专项训练 | 按知识点（而非题型）成套训练，如“乘法口诀”“多音字”“三会词汇”。按“理解 → 基础练 → 变式 → 综合”梯度组织，题数由家长指定；与 F2（按题型）的区别见 4D |

### 2.2 英语听力

- 生成听力原文 + 音频（mp3）：题号播报、每段读两遍、题间停顿、语速按年级调整
- 音频方案：macOS `say`（离线）为默认，可选 edge-tts（更自然，依赖网络）
- 纸质卷不能播放，产出时提示“配套 mp3”

### 2.3 闭环类（P3）

- 阅卷录入：家长阅卷表勾选每题得分与错因（粗心/概念/审题/计算/方法）
- 错题库：按孩子隔离，记录知识点、错因、日期；同题多次错合并计数
- 间隔复习：3 / 7 / 14 / 30 天回头，复习卷自动混入到期错题的变式
- 薄弱点统计：按知识点汇总正确率，供“专项卷”选题

## 3. 输出规范

每次产出 3 类文件，**孩子卷与答案卷必须分离**：

| 文件 | 受众 | 内容 |
|---|---|---|
| `试卷.md` / `.pdf` | 孩子 | 仅题目与作答区，无答案无提示 |
| `答案与评分.md` / `.pdf` | 家长 | 答案、得分点、评分细则、一两句讲解提示、**阅卷表**（得分 + 错因勾选） |
| `听力.mp3` | 孩子 | 仅英语卷 |

- MD 为可编辑源文件，PDF 由脚本一键渲染（A4，黑白打印友好）；家长改完 MD 可重新渲染
- 题目与试卷先落**结构化中间格式（JSON）**，MD / PDF / 答案卷 / 错题入库都由它渲染
- 版式：语文拼音格/田字格，数学算式留白区，英语四线三格；低年级字号大、留白多；数学几何/统计图由代码生成（SVG/matplotlib）

## 4. 数据与存储

### 4.1 教材数据（随插件分发，进仓库）

- 只存**结构化元数据**：单元目录、知识点、生字词表、词汇句型表、必背篇目；**不存教材全文**（版权）
- 按册存放，每个文件记录：教材版本、版次、来源、校对日期
- 来源：国家中小学智慧教育平台（basic.smartedu.cn）电子教材（苏教版数学/译林版英语是否齐全待确认），及出版社官方资料
- 校对节奏：每学期开学前（2 月、8 月）校对一次；skill 使用时若数据校对日期超过 6 个月则提醒
- 以《义务教育课程标准（2022 年版）》为纲，知识点标注能力层级（识记/理解/应用/综合）

### 4.2 个人数据（**不进仓库**）

- 存放位置：本机 `~/.primary-exam/`
- 内容：孩子档案、错题库、出题记录、成绩
- 孩子档案：昵称、入学学年、教材版本、当前学习进度（学到哪个单元）
- 年级由“入学年份 + 学期起始日期”推算，学年更替无需手动改
- 两个孩子数据完全隔离；入口以“给老大/老二出……”识别
- 错题图片中的姓名、班级等信息不写入产物

## 4A. 试卷结构、评分与题量

- **100 分制**，不设卷面分。每科、每年级、每种卷（单元/期中/期末）有固定的大题结构与分值模板，合计必须为 100
- 模板参考公开的常见卷面的**结构、分值、题型分布**（来源见 `reference/exam-structure-research.md`），不照搬原题
- 评分细则要细到可执行：数学的步骤分、单位漏写、应用题漏答句；语文的错字/漏字/多字；英语的拼写错误；写入答案卷
- **题量规则**：
  - 整卷（单元/期中/期末）按常规一张试卷的题量出，不做时长限制
  - 专项练习（F1/F2）出题前先问家长要几题，不替家长决定
- 口算卡按年级关键点分阶段，例如二上乘法口诀、二下表内除法与有余数除法、三年级万以内加减与两三位数乘一位数

## 4A-2. 试卷模板的研究范围与培养导向

- 模板覆盖**单元测验、期中、期末**三类，不局限南京：参考江苏及全国各地（含统编教材配套的常见做法）的卷面结构，再按“怎样更好地培养孩子”取舍
- 培养导向（高于“像真卷”）：重基础与方法而非难题怪题；考查理解与应用，减少机械重复；语文重积累与表达、数学重算理与思维、英语重听说与语感；拔高题少而精并单独标注
- 每个模板文件注明：参考来源、适用年级/册次、题型与分值、能力层级分布；来源仅作结构参考，不照搬原题
- 总体取向“高要求、基础牢”：基础题不降标准，拔高题少而精并单独标注（详见 `reference/exam-structure-research.md`）
- 不依赖学校真卷：按正常出题思路，用**难度等级**控制卷面，不做真卷校准

### 难度等级（卷级参数，默认“标准”）

每题标 `tier`（基础/中档/拔高），整卷再选一个等级，决定按**分值**计的比例：

| 等级 | 基础 | 中档 | 拔高 | 适用 |
|---|---|---|---|---|
| 基础卷 | 85 | 15 | 0 | 刚学完新单元、查漏补缺、孩子状态不佳时 |
| **标准卷（默认）** | 70 | 20 | 10 | 日常单元测验、期中期末 |
| 提高卷 | 50 | 30 | 20 | 学有余力、冲刺式训练 |

- 无论哪一级，**基础题标准不降**（口算、字词、核心句型全部按本册要求），只调整中档与拔高的占比
- 孩子档案记录每科当前等级；做完后按反馈（太难/刚好/太简单）建议升降一级，由家长确认
- 拔高题只放在固定位置（解决问题末题、课外阅读末题、习作、英语阅读末题），单独标注，答案卷写明考查点

## 4A-3. 图形题（题目含图）

- 题目可含图，图须**由代码生成**（SVG/matplotlib），保证数据与答案严格一致，不用 AI 随手画
- 图类型：数学（图形与几何、长度/角、统计图表、数射线、找规律图、时钟）、英语（看图选词/看图说话所需简笔画场景、时钟/天气/物品）、语文（看图写话配图，来源为原创或公版素材，不用教材插图）
- JSON 中每题可带 `figure` 字段（类型 + 参数），渲染时转 PNG/SVG 嵌入 MD 与 PDF；答案卷可带标注版配图
- 核验：图中数值与题干/答案一致（脚本复算）；黑白打印清晰（不靠颜色区分）；尺寸适配 A4；缺图时拒绝出卷而不是静默跳过
- P0 先验证“代码生成图 → 嵌入 MD → Chrome 打印 PDF”整条链路，P1 起题型逐步带图

## 4B. 分科要点

**语文**：拼音与字词（多音字、形近字、同音字）、句子训练（扩句/缩句/修辞/改病句）、积累运用（古诗默写、日积月累、课文填空）、阅读理解（课内/课外分层，短文原创或公版）、二年级看图写话与三年级习作（含评分量规：内容/语句/书写/标点）。识字表（认读）与写字表（会写）出题范围不同，须区分。

**数学**：口算、竖式与脱式、单位换算、估算、找规律与数学广角、图形与几何、统计图、应用题数量关系与一题多解。题目只能使用**该单元之前已学**的知识点（超纲检查）。

**英语**：听说读写按年级定权重，三上以听力与看图选词为主、书写要求低；区分三会/四会词汇，题目不超出范围；覆盖 Sounds in focus 语音题、Story time 阅读、情景交际；“说”不能纸笔考，提供家长口头抽查清单。

## 4C. 学习诊断与错题教学

- **起始诊断**：首次使用先出覆盖前几册重点的诊断卷，生成各知识点掌握度，之后的专项选题依据它（提前到 P1）
- **错因细分**到学科：数学（进退位错、单位错、漏条件、公式混淆）、语文（形近字混淆、拼音声调错）、英语（拼写、语序、词义）
- **订正与讲评**：答案卷附“家长讲评提示”，给出引导话术而非直接给答案；流程为 孩子自己订正 → 讲给家长听 → 数日后重做
- **难度校准**：家长录入每题对错后，累计实际通过率，反推并校正后续难度标注；难度档位按孩子单独记录

## 4D-1. 错题定向专项（F1）

**两种输入，走同一条流程**：
- A. 图片：家长拍的作业/试卷错题照片（可多张）；也支持 PDF、doc、MD
- B. 文字：家长直接列出错题（题干 + 孩子的错误答案，可选正确答案），如“23+49 孩子写了 62”

**流程**：
1. **识别**：图片由 Claude 直接读图提取；印刷体可辅以本机 OCR（`notes-from-docs` 里的 Apple Vision 脚本）。手写批改痕迹（红叉、红笔订正）用来判断哪题错了、孩子写了什么
2. **家长确认**（必须）：把识别出的“题干 / 孩子的答案 / 正确答案”列成清单让家长核对、改错，确认前不入库不出题。无法辨认的写“待确认”，不猜
3. **核对正确答案**：数学由脚本复算；语文/英语对照本册字词表与教材范围；与家长给的答案不一致时提示，不擅自判定
4. **错因归类**：按 4C 的学科错因表归类（如进位错、单位错、形近字混淆），家长可改；一题可多因
5. **映射知识点**：对应到知识点目录的编号（目录建好前先用单元 + 自由描述），无法映射的标“待归类”
6. **生成专项**（先问总题数，默认 12–20 题）：每道错题生成
   - 同构变式 1–2 题（同知识点、同错因、换数据/情境）：验证真的会了
   - 迁移变式 0–1 题（同知识点、换题型）：避免只会套模板
   - 并按错因补 1–2 道“前置基础”题（如进位错 → 先练个位凑十），默认标准卷比例，可调难度等级
7. **出卷**：孩子卷不含原错题和提示；答案卷里列“原错题 → 错因 → 本卷对应题号”，并附讲评提示；可选再附“原题重做”一页（间隔几天后让孩子重做原题）
8. **入库**：确认后的错题写入 `~/.primary-exam/` 错题库（按孩子隔离），同题再错则合并计数，供 P3 间隔复习

**规则**：
- 不照搬原题到变式题；变式与原题要有可检查的差别（数据/情境/结构）
- 照片里孩子的姓名、班级、学校不写入产物和错题库
- 一次导入题量很大时，按错因/知识点聚类，由家长勾选要练的类别，避免出成超长卷
- 只一张图、只一题也能用；不要求凑满整卷
- 分期：文字列题和图片识别两种输入都进 P1（家长确认 → 错因 → 变式专项）；第 8 步入库、间隔复习与薄弱点统计留在 P3，P1 阶段错题仅用于当次出卷

## 4D. 专项训练（F2 题型 / F8 知识点）

| | F2 题型专项 | F8 知识点专项 |
|---|---|---|
| 维度 | 题的形式：看拼音写词语、竖式计算、连词成句 | 要掌握的内容：乘法口诀、进位加法、多音字、单词 /ai/ 发音 |
| 题目组成 | 同一题型反复练 | 同一知识点跨多种题型，由浅入深 |
| 典型用途 | 提速、熟练、应试形式 | 补弱、巩固概念、打牢基础 |

**知识点专项的梯度**（题数由家长指定，按比例分配）：
1. **理解**（约 15%）：概念、算理，一两道判断/填空，答案卷附讲解要点
2. **基础练**（约 40%）：核心题型，对应基础档
3. **变式**（约 30%）：换情境、换数据、易错点（含进退位、含 0、形近字等）
4. **综合**（约 15%）：与相邻知识点结合，含 1 道中档/拔高题，按难度等级调整

**知识点目录**（`data/knowledge/<学科>/<学科>_g<年级>_<up|down>.json`，按册一个文件，`scripts/validate_knowledge.py` 校验）：
- 每个知识点：编号、名称、所属单元、教材页码、课标出处、能力层级、前置知识点、掌握标准、典型错因、适用题型
- **课标定“教什么、教到什么程度”，教材定“哪册哪单元学、先后顺序”**：课标来源为教育部官网《义务教育课程标准（2022 年版）》三科 PDF（扫描件，本机 OCR，存 `textbooks-local/curriculum-standards/`，不提交）；教材来源为各册电子教材的课题标题和每单元末尾的“评价与反思”
- 能力层级采用课标附录给出的行为动词：了解 / 理解 / 掌握 / 运用（数学附录2有官方定义）
- 教材里有但课标未单列的内容，按教材补入；仅凭练习题型推断、没有专门例题的，在 `note` 里标明待对照教材确认
- 已建样例：`math/math_g2_up.json`（35 个知识点）；其余册按同样方式铺开
- 与错题库联动：错题按知识点编号入库，薄弱点统计直接给出可训练的专项清单

**入口示例**：“给老二出 20 题乘法口诀专项”“给老大做三下 Unit 3 单词 /i:/ 发音专项”“针对进位加法出一组变式”。题数未指定时先问。

## 5. 出题质量规则

- 每道题标注：单元、知识点、能力层级、预估难度
- 难度三档：基础巩固 / 标准 / 拔高；低年级默认偏稳，拔高题占比小并单独标注
- 默认题量与时长（可覆盖）：日常专项约 15-20 分钟；单元测验约 30 分钟；期中/期末按学校惯例
- 期中/期末使用双向细目表控制知识点覆盖与难度比例（约 基础:中档:拔高 = 7:2:1）
- 原创：不照搬教辅与真题原文；阅读材料用原创或公版文本
- 内容适合儿童；同批试卷内及与历史出题记录去重
- **机械核验（出卷前必须通过）**：
  - 数学：脚本复算全部答案
  - 英语：选择题答案唯一；词汇不超出本册词表
  - 语文：生字/词语在本册范围内；看拼音写词语拼音正确
  - 数学：只用已学知识点（超纲检查）；应用题数据符合生活常识
  - 试卷总分 = 100，各大题分值之和一致
  - 所有题目 schema 校验、去重校验
- 通过核验的好题沉淀为题库，同知识点可复用并用于去重
- 反馈调节：做完后记录“太难/刚好/太简单”与用时，调整后续默认难度

## 6. 入口与交互

- 一句话入口：如“给老大出一份第三单元的数学测验”，年级、册次、题量等自动补全
- 缺关键参数时主动追问，不猜测；专项练习必须先问题数
- 参数全集：孩子 / 科目 / 范围（单元或期中期末）/ 题型 / 难度 / 题量 / 时长 / 是否出答案卷

## 7. 明确不做

- 在线答题与自动批改（家长阅卷）
- 手写答案拍照自动判分（家长录入结果）
- 排名或与同龄人比较
- 第一版不做 1、4-6 年级及其他科目（保证结构可扩展即可）

| 阶段 | 内容 |

| **P0 底座** | 孩子档案、二/三年级教材数据、中间格式 JSON、MD→PDF 渲染、答案卷分离 |
